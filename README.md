# FileSort

A simple Python tool that automatically organizes files into folders based on their file extensions.

## Features

* Organizes files by category
* Supports images, documents, music, videos, and code
* Automatically creates category folders
* Moves unsupported file types to `Others`

## Technologies

* Python
* os
* shutil

## Usage

Run the program from the project root:

```bash
python src/organize.py
```

The program reads files from the configured folder and organizes them automatically.

## Categories

* Images
* Documents
* Music
* Videos
* Code
* Others

## Requirements

No external dependencies are required.
